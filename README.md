# Barber Pro · Gestión de barbería (demostración)

Aplicativo web para barberías con dos partes:

- **Sitio público:** servicios con duración y precio, agenda disponible en tiempo real, reserva en 4 pasos y confirmación con abono mínimo, catálogo de productos y consulta de citas por celular.
- **Panel del equipo:** agenda por barbero, verificación de abonos, cobro de servicios, clientes, servicios editables, inventario y ventas de productos, caja y contabilidad, reportes y comisiones, configuración.

## Demostración

Versión de demostración: viene con datos de ejemplo y cada visitante trabaja sobre su propia copia (se guarda en su navegador). Los pagos son simulados.

Acceso del equipo: botón **«Acceso barberos»**
- Administrador: PIN `1234`
- Barberos: PIN `0000`

## Tecnología

Una sola página HTML/CSS/JavaScript sin dependencias. Se publica con GitHub Pages.
